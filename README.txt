KARTHIKEYAN - CLOUD & DEVOPS PORTFOLIO

Files:
- index.html  -> Main portfolio website. CSS is embedded in this file.
- script.js   -> Responsive navigation, active-section highlighting, back-to-top button and dynamic year.

How to run:
1. Extract the ZIP.
2. Keep index.html and script.js in the same folder.
3. Double-click index.html or open it in a browser.

No server or external framework is required.
